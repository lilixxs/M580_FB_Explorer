# M580_FB_Explorer 使用說明

網頁在瀏覽器中解析 Control Expert 交換檔案。網頁不上傳匯入的檔案。網頁不連接 PLC。

本文截圖只使用內建範例。

## 1. 介面語言

頂欄提供語言切換入口。可選簡體中文、英文、繁體中文、日文和韓文。

瀏覽器允許本機儲存時，網頁記住語言選擇。

切換語言不清空文件、原始碼和未匯出的修改。

介面操作與提示使用目前語言。PLC 識別碼、使用者檔案內容和 XML 格式值不隨介面語言改變。

已產生的狀態訊息和解析警告保留產生時的語言。後續操作使用新選定的語言。

## 2. 匯入檔案

![工作區](images/zh-TW/workspace.png)

點擊頂欄「匯入檔案」選擇 .xdb、.xst 或 .xsy 檔案。也可以把檔案拖到視窗中。

點擊頂欄範例按鈕可以載入內建範例。

匯入和匯出入口只在頂欄。左上面板不提供匯入和匯出按鈕。

左上區域顯示檔案資訊、程式區段清單和解析警告入口。

點擊程式區段後，右下編輯器顯示對應內容。

每次只編輯一個文件。重新匯入會取代目前文件。請先匯出修改後的檔案。

匯入成功後，網頁清空搜尋詞和摺疊狀態。

網頁支援單個 FBSource 的 .xdb 檔案、程式區段 .xst 檔案和變數表 .xsy 檔案。多功能區塊作用域暫不合併。對於無法安全處理的結構，網頁拒絕匯入並顯示原因。

非 ST 程式區段顯示唯讀 XML 原文。網頁不把圖形語言轉換為 ST。

## 3. 新建功能區塊

![新建功能區塊](images/zh-TW/new-block.png)

點擊頂欄「新建功能區塊」開啟對話框。

在對話框中輸入功能區塊名稱，並可填寫註解。

名稱必須符合本專案的 IEC 識別碼規則。

確認後，網頁建立空變數表和一個空 ST 程式區段。

目前文件含未匯出的修改時，取代前網頁徵求確認。

新建文件使用現有變數編輯、ST 編輯、儲存和 .xdb 匯出流程。

## 4. 中繼資訊編輯

功能區塊名稱與註解使用草稿編輯。

輸入新值後，點擊「確認」才寫入文件。

點擊「取消」還原原值。

## 5. 版面與引腳檢視

左右分欄預設佔 34% 和 66%。右上變數清單預設佔高度的 1/3。右下程式區段編輯器預設佔高度的 2/3。

左欄依次顯示中繼資訊、呼叫清單和引腳檢視。拖動分隔線可以調整各面板尺寸。雙擊分隔線可以重設。聚焦分隔線後，可以按方向鍵微調尺寸。

網頁在窄螢幕上改為垂直排列。面板內的表格支援橫向捲動。瀏覽器允許本機儲存時，網頁記錄面板尺寸。

引腳檢視顯示 IN、OUT 和 IN_OUT。IN_OUT 使用虛線識別。PRIVATE、PUBLIC 和 GLOBAL 不繪製為引腳。EN 和 ENO 僅作為系統引腳示意。點擊引腳可以定位右上變數。

使用引腳面板的加減按鈕可以縮放檢視。點擊引腳時，網頁清空變數搜尋詞並展開對應分組。

點擊引腳或變數列後，編輯器定位該變數的使用位置。呼叫面板顯示相關變數參照。沒有參照的變數不觸發無關跳轉。

## 6. 變數管理

![變數編輯器](images/zh-TW/variable-editor.png)

變數按 IN、OUT、IN_OUT、PUBLIC、PRIVATE 和 GLOBAL 分組。GLOBAL 對應 dataBlock 全域變數。

在搜尋框輸入變數名、型別、位址、初值或註解。搜尋時自動展開符合分組。點擊分組標題可以摺疊分組。

點擊「新增」建立變數。點擊「改」修改變數。點擊「刪」後確認刪除。點擊上下箭頭調整同類變數順序。引腳序號 PositionPin 依順序重新計算。

![型別選擇](images/zh-TW/type-picker.png)

點擊「選擇型別」可以點選基礎型別。也可以輸入自訂型別。陣列模式提供元素型別、下界和上界。產生結果使用 ARRAY[下界..上界] OF 型別。

變數表分別顯示型別和位址。捲動變數表時，目前分組標題吸附在表格頂端。

變數名必須以英文字母或底線開頭。其餘字元只允許英文字母、數字和底線。變數名不得在忽略大小寫後重複。EN 和 ENO 不能新增為普通引腳。

32 位元型別繫結 %MW 時必須使用偶數位址。網頁不擅自改變位址。請在變數對話框中修改錯誤位址。

## 7. ST 呼叫解析

![呼叫瀏覽](images/zh-TW/call-browser.png)

左中清單顯示函數和功能區塊呼叫。清單保留未知呼叫，不把未知名稱視為系統函數。解析器忽略字串和註解中的偽呼叫。

點擊呼叫項後，編輯器跳轉到對應行列。點擊「重新解析」重新解析程式碼。儲存程式區段也會刷新呼叫清單。

呼叫面板同時提供普通變數參照。參照分析忽略註解、字串和具名參數的形參名。點擊參照會同步定位程式碼、變數列和對應引腳。編輯器點擊變數也會更新選取狀態。

呼叫解析不等於語法編譯。網頁不檢查所有函數簽章，也不執行 ST 程式碼。

## 8. 編輯器操作

| 操作 | 入口 |
| --- | --- |
| 尋找 | Ctrl+F、工具列、右鍵選單 |
| 取代 | Ctrl+H、工具列、右鍵選單 |
| 行列跳轉 | Ctrl+G 或 行:列 輸入框 |
| 格式化 | Shift+Alt+F、工具列、右鍵選單 |
| 插入 IF / FOR / WHILE | 工具列、右鍵選單 |
| 函數/功能區塊呼叫 | 工具列、右鍵選單 |
| 儲存並解析 | Ctrl+S 或儲存按鈕 |
| 自動完成 | 輸入時提示或 Ctrl+空白鍵 |

自動完成包含關鍵字、目前變數、常用函數和語句模板。格式化器只整理已支援的 ST 結構，不取代完整的 IEC 61131-3 編譯器。

編輯器儲存只寫入頁面記憶體。儲存不修改磁碟上的原始檔案。請點擊頂欄「匯出 .xdb」下載修改後的檔案。

儲存並重新解析後，目前程式區段的「未儲存」標記消失。頂欄「有修改」表示尚未匯出，不會因儲存程式區段而消失。

「函數/功能區塊呼叫」彈窗分為分類欄和項目欄。彈窗支援搜尋、函數、功能區塊、目前文件程式區段和自訂呼叫。插入位置為開啟彈窗時的編輯器選取區或游標。

EFB 必須使用實例。選擇已有同型別實例，或輸入新實例名並確認建立 PRIVATE 變數後再插入。插入後請檢查參數和呼叫位置。程式區段名呼叫不保證適用於所有任務上下文。

函數與變數型別資料來自 src/data/functionLibraries/ 下的 JSON。基礎快照不代表完整官方手冊。每個函式庫說明來源和涵蓋範圍。維護方法見倉庫 CONTRIBUTE.md。修改 JSON 後必須重新建置。

Standard 函式庫資料來自 33002519.20（09/2020，適用 Control Expert 15.0 以上）。目錄已單獨保存。呼叫清單只包含已核實的具體函數。變數型別說明來自 35006144.27。舊預設中的擴充型別不表示已核實 M580 支援。Unity Pro V13.1 相容性未驗證。

Monaco 載入失敗時，網頁顯示錯誤並切換到文字框。文字框不提供語法高亮和自動完成。

## 9. 匯出規則

匯出器按倉庫 AGENTS.md 第 4 節產生 XML。

- STSource 只允許可執行語句。偵測到 VAR 宣告區時，網頁拒絕匯出。請把變數放入變數表。
- 輸入、輸出和雙向參數分別寫入對應容器。PositionPin 從 1 遞增。
- 功能區塊初值寫入 variableInit。全域變數初值讀取 defaultValue。
- 空 topologicalAddress 和空 comment 會省略。
- 匯出器展開自閉合標籤。
- 32 位元 %MW 變數必須繫結偶數位址。校驗失敗時拒絕匯出。
- .xdb 寫回時保留未編輯的擴充節點和屬性。

從 .xst 或 .xsy 匯出 .xdb 屬於結構轉換。GLOBAL 變數會轉為 PRIVATE。網頁顯示轉換警告。程式區段的任務上下文不會變成 PLC 任務。請檢查轉換結果。

匯出包含警告時，網頁在「匯出說明」抽屜顯示警告全文。

Control Expert 匯入、編譯和真機通訊測試均未執行。

## 10. MCP 預留介面

網頁提供 window.__M580_MCP_BRIDGE__。Bridge 提供 listTools()、callTool(name, input) 和 getState()。

這是本頁內的工具介面，不是獨立的 MCP Server。網頁不預設連接遠端服務。傳輸配接器只提供接取邊界。

| 工具 | 用途 |
| --- | --- |
| m580_fb_get_metadata | 讀取文件摘要 |
| m580_fb_list_variables | 按 category 和 search 查詢變數 |
| m580_fb_upsert_variable | 按 id 修改變數，或新增變數 |
| m580_fb_delete_variable | 按 id 刪除變數 |
| m580_fb_get_source | 按 sectionId 讀取程式碼 |
| m580_fb_set_source | 寫入 source 並解析呼叫 |
| m580_fb_insert_snippet | 在 line、column 插入 source 或 kind 模板 |
| m580_fb_analyze_calls | 重新提取呼叫 |

保留以下相容工具：m580_get_state、m580_import、m580_list_variables、m580_upsert_variable、m580_delete_variable、m580_get_section、m580_set_section_source、m580_save_section、m580_format_section、m580_replace_in_section、m580_extract_calls、m580_export_xdb、m580_get_help、m580_jump。

查看 listTools() 回傳的 inputSchema 取得各工具的欄位和必填參數。callTool() 回傳 ok、result 或 error。

範例：

```js
await window.__M580_MCP_BRIDGE__.callTool('m580_fb_list_variables', { category: 'IN' })
```

## 11. 部署與更新

執行 npm run build 後，把 dist/ 整體複製到靜態檔案伺服器。支援部署到子路徑。不要用 file:// 直接開啟。Monaco Worker 需要透過 HTTP 或 HTTPS 載入。

建置產物包含頁面、樣式、腳本和 Worker。建置產物不依賴外部 CDN。

說明真源為 requirements/localization/help/ 目錄下的 zh-CN.md、en.md、zh-TW.md、ja.md 和 ko.md。應用透過 Vite raw 方式載入目前語言的 .md 檔案。建置器把說明檔案複製為 dist/HELP.{locale}.md，並產生預設 HELP.md。README.md 由 README.en.md 的副本產生。

每次功能變更必須同步更新說明文件和 docs/requirements.md。每次交付必須重新執行型別檢查、單元測試和建置。
