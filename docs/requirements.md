# M580_FB_Explorer 网页需求规格

## 1. 目标

`M580_FB_Explorer` 提供 M580 Control Expert 功能块文件的浏览和编辑界面。

网页使用 Vue 3、TypeScript、Vite、TDesign Vue Next 和 Monaco Editor。

网页构建产物写入 `M580_FB_Explorer/dist/`。

网页使用相对资源路径。

网页可以部署在静态文件服务器或子路径中。

## 2. 文件范围

网页支持导入 `.xdb`、`.xst` 和 `.xsy` 文件。

网页解析 XML 文件中的功能块名称、版本、注释、变量和程序段。

网页支持把当前功能块导出为 `.xdb` 文件。

导出器必须保留变量分类和引脚顺序。

导出器必须省略空的 `comment` 和 `topologicalAddress` 属性。

导出器必须把自闭合 XML 标签展开为成对标签。

网页不执行 Control Expert 编译。

网页不执行 PLC 真机通信测试。

## 3. 数据模型

### 3.1 变量分类

网页使用以下变量分类：

| 分类 | XML 节点 |
| --- | --- |
| `IN` | `inputParameters` |
| `OUT` | `outputParameters` |
| `IN_OUT` | `inOutParameters` |
| `PUBLIC` | `publicLocalVariables` |
| `PRIVATE` | `privateLocalVariables` |

`.xst` 和 `.xsy` 文件中的 `dataBlock` 变量归入独立的 `GLOBAL` 分类。

把 `GLOBAL` 导出为 `.xdb` 时，网页必须说明变量将转为 `PRIVATE`。

网页必须拒绝会混合多个功能块变量作用域的输入。

网页不得把未知调用直接归类为系统函数。

`.xdb` 写回必须保留未编辑的扩展节点和属性。

导出器检测到 ST 声明区时必须拒绝导出。网页不得静默删除声明。

### 3.2 变量字段

每个变量必须包含名称和类型。

网页显示变量名、变量类型、初值、注释和引脚序号。

网页保留 `topologicalAddress` 和 XML 初值属性。

变量名只允许使用字母、数字和下划线。

变量名必须以英文字母或下划线开头。

网页必须忽略大小写检查重复变量名。

网页禁止新增 `EN` 和 `ENO` 变量。

网页修改输入、输出和双向引脚后，必须重新计算 `PositionPin`。

## 4. 页面布局

页面使用左右分栏。

页面允许拖拽左右分隔条。

左栏默认占 34%。

右栏默认占 66%。

左栏包含上、中、下三个区域。

左上区域显示功能块元信息和程序段。导入和导出统一使用顶栏入口。

左中区域显示程序段调用分类表。

左下区域显示功能块调用视图。

左栏的两个水平分隔条均支持拖拽。

分隔条支持双击复位。

分隔条支持方向键微调。

网页在浏览器允许时保存面板尺寸。

引脚视图支持缩放。

点击引脚后，网页必须展开对应变量分组并定位变量。

右栏包含变量列表和程序段编辑器。

右上区域默认占右栏高度的三分之一。

右下区域默认占右栏高度的三分之二。

右栏的水平分隔条支持拖拽。

页面在窄屏幕上必须改为垂直布局。

顶栏提供文件导入、文件导出和内置示例入口。

网页支持拖入交换文件。

导入成功后，网页必须清空上一个文档的搜索词和折叠状态。

左上区域必须提供解析警告列表。

导出产生转换警告时，网页必须显示警告全文。

## 5. 变量列表

变量编辑器必须提供类型选择界面。

用户可以点选基础类型。

用户可以输入自定义类型。

用户可以选择数组元素类型和上下界。

编辑已有数组时，类型选择界面必须回填元素类型和上下界。

数组上下界必须为安全整数。下界不得大于上界。

变量列表必须分列显示类型和地址。

当前变量分组标题必须吸附在变量列表滚动区域的顶端。

变量列表按 `IN`、`OUT`、`IN_OUT`、`PUBLIC`、`PRIVATE` 和 `GLOBAL` 分组。

每个分组支持展开和折叠。

搜索框匹配变量名、类型和注释。

用户可以新增变量。

用户可以修改变量名称、类型、初值和注释。

用户可以删除变量。

用户可以调整引脚变量顺序。

网页在保存变量前校验变量名和重复项。

网页保存程序段时不得丢弃变量修改。

保存操作只更新页面内存。用户必须导出文件以保留修改。

32 位变量绑定 `%MW` 时必须使用偶数地址。网页不得自动修改地址。

## 6. 程序段解析

网页识别 `STSource` 节点并显示 ST 程序段。

网页识别非 ST 程序段并显示 XML 原文。

非 ST 程序段使用只读模式。

ST 解析器提取功能、功能块和函数调用。

解析器忽略注释和字符串中的伪调用。

调用项必须记录名称、分类、行号、列号和代码片段。

用户点击调用项后，编辑器跳转到对应位置。

用户可以手动刷新程序段解析。

用户保存 ST 程序段后，网页自动刷新调用列表。

调用面板必须提供普通变量引用视图。

变量引用必须记录程序段、行号和列号。

变量引用分析必须忽略注释、字符串和命名参数的形参名。

点击变量引用后，网页必须同步定位编辑器、变量列表和对应引脚。

点击变量行或引脚后，网页必须显示相关引用。

没有引用的变量不得触发无关跳转。

用户在编辑器中点击变量时，网页必须同步选中变量。

## 7. ST 编辑器

ST 编辑器使用 Monaco Editor。

编辑器提供 IEC 61131-3 ST 语法高亮。

编辑器支持搜索、替换和行列跳转。

编辑器支持 ST 程序格式化。

编辑器支持插入 `IF`、`FOR` 和 `WHILE` 模板。

编辑器右键菜单提供相同的主要操作。

编辑器自动提示 ST 关键字、当前变量和常用函数名。

编辑器保存操作支持 `Ctrl+S` 和界面按钮。

编辑器必须提供「函数/功能块调用」按钮和同名右键入口。

调用弹窗必须分为分类栏和条目栏。

调用弹窗必须支持函数、功能块、当前文档程序段和自定义调用。

调用弹窗必须提供搜索和函数库分组。

插入操作必须使用打开弹窗时的编辑器光标或选区。

EFB 调用必须使用已声明的实例，或显式创建新实例。

取消插入不得新增变量。

函数库和变量类型定义必须保存在 `src/data/functionLibraries/` 的 JSON 文件中。

官方资料条目必须记录来源。函数库必须说明覆盖范围。

新增同结构 JSON 后，构建器必须自动加载该库。

基础快照不得被表述为完整官方基础库。

官方目录必须与可插入函数清单分开保存。

通配名称不得作为具体函数插入。

变量类型说明必须区分已核实类型与未核实旧预设。

手册版本与目标编译器版本不同的条目必须注明兼容性未验证。

保存成功后，当前程序段的「未保存」标记必须消失。

顶栏「有修改」必须继续表示尚未导出的文档修改。

## 8. 视觉规范

所有页面组件使用直角边框。

所有组件的 `border-radius` 必须为 `0`。

页面背景使用 `#FAF9F5`。

内容区域使用 `#FFFFFF`。

强调色使用 `#D97757`。

主边框使用 `#CFCAC0`。

次级分隔线使用 `#E5E2D8`。

界面文字使用系统无衬线字体。

代码、变量名和类型使用等宽字体。

页面必须保留键盘焦点样式。

## 9. 帮助文档

网页提供顶栏帮助入口。

帮助内容使用抽屉显示。

帮助文档必须说明文件导入、变量编辑、程序段解析、编辑器快捷键和导出规则。

帮助文档必须说明 MCP Bridge 的工具名称和参数。

每次功能变更必须同步更新本文件和网页帮助内容。

构建器必须从帮助真源同步生成 `dist/HELP.md` 和 `dist/README.md`。

## 10. MCP 预留接口

网页暴露 `window.__M580_MCP_BRIDGE__`。

Bridge 提供工具 Schema 和本地调用方法。

Bridge 至少提供以下工具：

1. `m580_fb_get_metadata`。
2. `m580_fb_list_variables`。
3. `m580_fb_upsert_variable`。
4. `m580_fb_delete_variable`。
5. `m580_fb_get_source`。
6. `m580_fb_set_source`。
7. `m580_fb_insert_snippet`。
8. `m580_fb_analyze_calls`。

Bridge 不默认启动本地服务。

Bridge 必须校验必填参数、参数类型和分类枚举。

传输适配器必须明确标记为未连接的桩。网页不得将其标记为可用的 MCP Server。

## 11. 测试与验收

测试必须覆盖 XML 解析、XML 导出、变量编辑、ST 调用解析、布局交互和 MCP Bridge。

测试必须覆盖真实的 `ModbusTCP_Client.xdb` 示例文件。

测试必须验证解析后导出的 XML 可以再次解析。

测试必须验证导出 XML 不包含自闭合标签。

测试必须验证输入、输出和双向引脚序号连续。

测试必须验证 ST 保存后调用列表更新。

构建命令必须生成 `M580_FB_Explorer/dist/`。

浏览器测试必须覆盖真实文件导入、变量增删改、程序段保存、文件下载、拖拽和移动端。

浏览器测试必须检查资源加载错误和意外的外部资源依赖。

验收报告必须分别说明静态检查、单元测试、构建测试和未执行的 Control Expert 测试。

## 12. 多语言与文档创建

界面使用 Vue I18n。语言文件独立存放，不把译文写入组件。

界面默认使用简体中文。顶栏提供英文、繁体中文、日文和韩文切换入口。

浏览器允许本地存储时，网页记住语言选择。语言切换不得清空文档、源码或未导出的修改。

界面操作、校验提示与帮助内容使用当前语言。PLC 标识符、用户文件内容和 XML 格式值不得随界面语言改变。

已生成的状态消息和解析警告保留生成时的语言。后续操作使用新选定的语言。

帮助文档按语言分别保存。每种语言提供对应界面的截图。截图只使用内置示例。

顶栏提供「新建功能块」。用户确认名称和可选注释后，网页创建空变量表与一个空 ST 程序段。

创建前校验名称。名称必须符合本项目的 IEC 标识符规则。文档含未导出修改时，替换前必须征求确认。

新建文档使用现有变量编辑、ST 编辑、保存和 .xdb 导出流程。

功能块名称与注释使用草稿编辑。用户点击「确认」后才写入文档。点击「取消」恢复原值。

「功能块与程序段」面板不再提供导入和导出按钮。顶栏保留统一入口。

测试必须覆盖语言持久化、语言文件键与占位符一致性、新建与导出回读、草稿确认/取消，以及重复按钮移除。
